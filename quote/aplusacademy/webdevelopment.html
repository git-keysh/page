Project Overview

What this project is

Nexus Command will work with A+ Academy to improve the website's performance, asset loading behavior, technical cleanliness, legal pages, and overall user experience.

The primary objective is to reduce unnecessary browser workload while preserving all functionality the website actually requires.

This is not a simple "remove JavaScript" process. Existing JavaScript assets will be audited first, dependencies identified, and only unnecessary functionality, duplicate logic, unused modules, or excessive framework-generated code will be removed or replaced.

The result is a cleaner, faster, more reliable website with a modern presentation.

What Nexus Command will do

Before removing or replacing these assets, Nexus Command will analyze their contents and determine:

  • Which modules are actually required by the website
  • Which JavaScript functionality is actively used
  • Which scripts are related to interactive website components
  • Which scripts are related to menus, forms, sliders, navigation, animations, or other required functionality
  • Which modules are framework-generated but unnecessary for the public-facing website
  • Which dependencies can safely be removed
  • Whether specific functionality can be replaced with smaller native JavaScript implementations
  • Whether removing a dependency creates errors elsewhere in the website

Optimization goal

The goal is not to blindly delete JavaScript. The goal is to filter the frontend asset pipeline so the browser receives only the functionality required to operate the website.

This can reduce:

Initial JavaScript payloadParsing & compilation workloadMain-thread executionUnnecessary network requestsFramework overheadDelayed renderingUnused frontend functionality

Console issues currently observed

The current website has produced frontend console messages including:

Add templates on window Owl container.
[WebsiteCustomHomeMenu] No result from load_menus
Tour Manager is ready. running_tour=null

There is also a browser warning concerning a preloaded Font Awesome font resource that was not used shortly after page load. These will be investigated to determine whether they are:

  • Required framework behavior
  • Unused website modules
  • Incorrectly loaded functionality
  • Legacy/template-generated functionality
  • Asset prioritization issues
  • Harmless informational messages
  • Actual performance problems
No functionality will be removed solely because it appears in the console.

The current website's media loading behavior will be reviewed and optimized. Important visual content is prioritized while non-critical media is prevented from competing with the initial page render.

Potential optimizations

  • Proper image loading priorities
  • Lazy-loading below-the-fold media
  • Responsive image handling
  • Correct image dimensions
  • Reducing unnecessary image requests
  • Optimizing media delivery
  • Improving above-the-fold rendering
  • Reviewing preload usage

The goal is to make the website feel significantly faster when a visitor first opens it.

05

Privacy Policy

A dedicated Privacy Policy page will be added to the website. The page will explain, where applicable:

  • What information the website may collect
  • How submitted information is handled
  • How contact information is used
  • How website data may be stored
  • Third-party services that may process information
  • Cookies and similar technologies
  • User rights and available choices
  • How users can contact the organization regarding privacy
The final policy should be reviewed and approved by A+ Academy before publication, because Nexus Command is providing the website implementation, not legal advice.

Why this matters

A Privacy Policy gives visitors transparency about how their information is handled. It is especially important when a website contains contact forms, registration systems, analytics, cookies, payment systems, or other data-collecting functionality.

  • Website usage
  • Acceptable use
  • Educational/service information
  • User responsibilities
  • Intellectual property

  • External links

Why Terms of Service matter

A Terms of Service page establishes the rules under which visitors are allowed to use the website and helps define the relationship between the website operator and its users. It can also provide important protections around website content, acceptable use, intellectual property, service availability, and liability.

The final terms should be reviewed and approved by A+ Academy or its legal representative before publication.
07

Robots.txt

A properly configured /robots.txt will be added and configured for the website. The file communicates crawling preferences to search-engine crawlers and can help search engines understand which areas of a website should or should not be crawled.

Important SEO clarification

robots.txt does not directly guarantee higher Google rankings. It is one component of technical SEO and crawler management. Nexus Command will configure it alongside the website's broader SEO structure so search engines can efficiently discover and crawl the intended public content.

Project Philosophy

Performance-first

Nexus Command will approach this project with a performance-first mentality. The objective is not to make the website smaller at the expense of functionality.

Load what is needed, when it is needed, and remove what provides no value to the visitor.
PRIORITY 1Performance
PRIORITY 2Functionality
PRIORITY 3User Experience

A faster website is only valuable if it remains stable, usable, and visually polished.

Important technical note

The existing JavaScript bundles will be analyzed before modification. Nexus Command will identify dependencies and functionality within the bundles before deciding what can safely be removed, deferred, replaced, or retained.

This prevents the common mistake of removing a large JavaScript file only to discover that it was responsible for important website functionality. The final implementation prioritizes measurable performance improvements while preserving required functionality.
