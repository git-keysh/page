🔐 core security & data management

cybersecurity vs computer security

Cybersecurity protects online assets, networks, cloud data.
Computer security focuses on physical machines, local storage & peripherals.

software security solutions

Firewall – filters traffic, blocks intrusion.
Antivirus – detects malware.
Firewall benefit: prevents unauthorised network access.

file organization: serial vs sequential

Serial: records appended as they arrive.
Sequential: sorted by key, used for magnetic tape archives.

threats matching (past paper)

Electronic eavesdropping → monitor communication.
Identity theft → gather personal info.
Industrial espionage → competitor advantage.

🧩 algorithms & pseudocode

characteristics of algorithms

1. finite & unambiguous
2. effective steps
3. zero or more inputs, one or more outputs
4. terminates after finite steps

total distance (50 employees)

START
totalDist ← 0
FOR i=1 TO 50
INPUT name, distance
totalDist ← totalDist + distance
NEXT
OUTPUT totalDist
END

coffee shop sales (IPO)

Input: shopName, Jan..Apr sales
Processing: total=sum, avg=total/4
Output: shopName, total, avg

READ shopName, s1,s2,s3,s4
total ← s1+s2+s3+s4
avg ← total/4
PRINT shopName, total, avg

payroll overtime (rate snippet)

IF hoursWorked > 40 THEN
overtimePay ← (hoursWorked-40)*6
pay ← (40*5)+overtimePay
ELSE
pay ← hoursWorked*5
ENDIF

VLOOKUP parameters

=VLOOKUP(lookup_value, table_array, col_index, [range])
P1: value to search, P2: table range, P3: column index, P4: FALSE for exact match.

✔️ validation & verification

validation checks

Range (0-100), Format (XXX-999999), Presence (not empty), Consistency (age matches DOB), Length (password min 8).

double data entry

User enters age twice; system compares both entries. If mismatch → error message → re-enter.

verification methods

Visual check: compare screen with original paper. Double entry: enter twice and compare.

word count in MS Word

Highlight text → Review tab → Word Count, or view status bar.

🌐 networks & web technologies

WAN / LAN / intranet

WAN connects remote LANs (different cities). Intranet: private. Extranet: external authorized access.

cloud vs local storage

Cloud: off-site, accessible from anywhere, automatic backup. Local: physical control, faster intranet access.

URL components

https:// protocol · www.cxc.org domain · /results path

hyperlink definition

Clickable element linking to another webpage, file, or section. Used in navigation bars, image links, call-to-action buttons.

🛡️ threats & countermeasures

ransomware & DoS

Ransomware encrypts files + demands payment. DoS attack overloads server, making service unavailable.

phishing & industrial espionage

Phishing via email/SMS: trick users into credentials. Espionage: stealing trade secrets from competitors.

firewall & antivirus

Firewall filters network traffic; antivirus scans & removes malware.

vulnerability vs threat

Vulnerability: weakness (e.g., outdated software). Threat: danger that exploits weakness (hacker).

📖 concise glossary

serial vs sequential

Serial: arrival order; Sequential: sorted by key — ideal for tape storage.

primary / foreign key

Primary: unique identifier (ItemNo). Foreign: link to another table (SupplierID).

syntax error

violates language grammar (e.g., missing quote, misspelled keyword).

telecommuting advantage

Reduced commute, flexible hours, lower office costs.

while vs repeat until

While checks condition before; Repeat until executes at least once.

grouping in reports

aggregates data by categories, e.g., total sales per region.
